About the Project

CineViewExperience is a fictional cinema website created for educational purposes, focused on offensive security.

The idea was to simulate a real platform, with registration, login, ticket purchasing, and everything such a system would include - but with intentionally inserted flaws for anyone who wants to learn security in practice.

The website was built with plain Python on the backend and HTML, CSS, and JavaScript on the frontend, using a PostgreSQL database and running with Docker to make local setup easier.

It is a test-focused environment, so it intentionally contains common vulnerabilities. It works both for beginners and for those who want to train with a more complete system.
